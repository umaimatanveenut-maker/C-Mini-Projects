# C Programming Beginner Projects

Welcome!

This repository contains 10 beginner-friendly C programming projects that I built before starting my Computer Science degree.

The goal of these projects wasn't to create production-ready software, but to strengthen my understanding of programming fundamentals through practical applications.

Each project helped me practice concepts such as:

- Variables
- Loops
- Conditional Statements
- Functions
- Arrays
- Strings
- File Handling
- Menu-Driven Programs
- Problem Solving

## Projects

- Smart Study Timer
- Student Progress Analyzer
- Expense Tracker
- Password Strength Checker
- Meme Quiz Engine
- Contact Book
- Library Management System
- Student Attendance Tracker
- ATM Simulator
- Splitwise Clone

More projects will be added as I continue learning.

Thanks for visiting!
